# Security Policy

## Supported Versions

Security fixes are generally provided for the latest published release of
LucidMenu. Older builds may no longer receive fixes after a newer release is
available.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | Best effort |
| Unofficial / redistributed builds | No |

## Reporting a Vulnerability

Please do not publish exploitable security issues in a public GitHub issue.

If the repository has GitHub Private Vulnerability Reporting enabled, use
**Security → Report a vulnerability** to submit the report privately.
Otherwise, contact the project maintainers through a private contact method
listed on the repository before disclosing technical details publicly.

A useful report should include:

- A concise description of the issue.
- The affected version.
- Reproduction steps or a minimal proof of concept.
- The potential security impact.
- Relevant logs or screenshots with sensitive information removed.

Please allow maintainers reasonable time to investigate and prepare a fix
before public disclosure.

## Scope

This policy covers security issues in official LucidMenu source code and
official project releases.

Third-party mirrors, repackaged builds, unrelated GTA V modifications, game
vulnerabilities, Rockstar services, anti-cheat bypasses, and GTA Online
exploitation are outside the scope of this project.

## Safe Use

LucidMenu is intended for GTA V Story Mode / offline singleplayer use.
Do not disable security software solely because a downloaded build asks you
to. Verify release provenance and back up important files before installing
third-party modifications.
